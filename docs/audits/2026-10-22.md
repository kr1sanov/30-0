# Аудит 30‑0 · 22 октября 2026

**Вывод:** основные автоматические сценарии и production-сборка проходят. При этом свежий код не подтверждён на Jino из-за сбоя SSH, фактические данные заканчиваются 2025 годом, реальная доставка Telegram требует отдельного подтверждения. Аудит не означает отсутствие всех ошибок или завершённое восстановление уведомлений.

**Код:** `9c217ba790c0f3e4d025020f2e268d7ddc49d222`, ветка main до обновления документации. **Продукт:** [Telegram Mini App](https://t.me/RPL30_bot?startapp). **Метод:** чтение кода и конфигурации, воспроизводимые локальные проверки, read-only диагностика production и реальные UI-действия. Изменения аудита в GitHub касаются документации, визуального оформления и безопасного примера окружения; перечисленные ниже задачи приложения не выдаются за исправленные.

## Охват

- Репозиторий: 457 отслеживаемых файлов на базовом коммите, 89 API route-файлов; клиент, сервер, Prisma, импорты, workflows, права и общие функции.
- Продукт: главная → Telegram-вход → настройки → новый драфт → прокрут → выбор игрока/позиции → возврат и возможность продолжить. Дополнительно: один клуб, челленджи и публичный результат.
- Автоматически: симуляция, исторические соперники, персональная статистика, мультиплеер, уведомления, редактор, дубли, роли и пользовательские челленджи.
- Источники: четыре актуальных набора 2006–2025 и отдельно старые seed JSON.

Не выполнялись: нагрузочный тест, внешний pentest, полный ручной просмотр всех 3 462 имён, проверка каждого API динамическими запросами, реальный матч на двух устройствах, Telegram iOS/Android, полный screen-reader/WCAG-прогон и фактическая отправка тестовых уведомлений. Админские сценарии проверены изолированными тестами; приватные production-экраны не публикуются. Production-данные не импортировались и не объединялись.
