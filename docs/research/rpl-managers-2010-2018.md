# Главные тренеры клубов РПЛ, 2010–2018

В `src/lib/managers.ts` находятся только главные тренеры первой команды, работавшие в соответствующем клубе хотя бы часть указанного периода. Идентификаторы клубов взяты из `rpl-2010-2018/registry.json`. Повторные назначения одного тренера объединены: в рулетке имя встречается один раз. Национальности и клубы проверены по спискам тренеров; игровые баллы 1–10 установлены редакционно и не выдаются за исторический рейтинг FIFA.
