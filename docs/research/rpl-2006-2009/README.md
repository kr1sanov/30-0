# Составы 2006–2009

Четыре приложенных пользователем файла `Russia Premier League YYYY.md` сохранены здесь без изменений. В каждом году 16 команд. Импорт переносит каждую строку таблицы в карточку игрока с исходным английским именем, кодом позиции, рейтингом Overall и Potential. Номер, возраст и гражданство отсутствуют в файлах и не заполняются.

| Сезон | Команд | Карточек игроков |
|---|---:|---:|
| 2006 | 16 | 439 |
| 2007 | 16 | 437 |
| 2008 | 16 | 443 |
| 2009 | 16 | 486 |
| **Всего** | **64 участия клубов** | **1 805** |

Сами файлы не содержат ID игроков или источников для проверки принадлежности к календарному сезону; годы используются как подписи предоставленных снимков. Отдельные клубы названы исторически (например, Terek Grozny), поэтому исходное название сохраняется в ClubSeason. Игровой интерфейс переводит коды позиций в внутреннюю схему, а исходный код позиции сохраняет отдельно. В файле 2008 две строки Dmitriy Smirnov в одной команде с разными позициями и рейтингами — обе сохранены как отдельные карточки.

Проверка без подключения к базе: `node scripts/import-rpl-2006-2009.mjs`. Импорт с резервной копией: `node --env-file=.env scripts/import-rpl-2006-2009.mjs --apply --backup=/private/roster-before-import.json`. Повторный запуск сравнивает все 1 805 карточек и не изменяет уже загруженные сезоны. Старый состав FIFA 10 2009 года заменяется снимком из приложенного файла; завершённые игры хранят данные выбранных игроков в слотах отдельно.
