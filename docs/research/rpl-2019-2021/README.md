# Составы 2019–2021

Данные перенесены из трёх Markdown-файлов, переданных владельцем проекта:
`Russia Premier League 2019.md`, `Russian Premier League 2020.md`,
`Russian Premier League 2021.md`. Исходные файлы содержат названия клубов,
имена, позиции, рейтинг, потенциал и номер; только файл 2019 года содержит
ID и гражданство. SHA-256 каждого исходного файла записан в JSON-снимке.
Название конкретного выпуска футбольной игры и календарные даты составов
из этих файлов установить нельзя, поэтому годы в игре обозначают годы файлов.

| Год файла | Клубов | Карточек игроков |
| --- | ---: | ---: |
| 2019 | 16 | 411 |
| 2020 | 16 | 391 |
| 2021 | 16 | 363 |

Всего 48 клубных составов и 1 165 карточек. 2019-файл указывает 27 игроков
ЦСКА в заголовке, но содержит 26 строк; отсутствующую строку не добавляли.
В файле 2020 года имя Víctor Álvarez дважды указано за «Арсенал Тула»
с разными номерами и позициями, так же как Danil Lipovoy за «Оренбург».
Оба случая сохранены отдельными карточками и отмечены в `duplicateNames`.

`rating` и `potential` переносятся без корректировки, в том числе когда
потенциал меньше рейтинга. Исходные позиции хранятся в `sourcePositions`.
Некоторые позиции представлены числами или кодами, которых нет в игре.
Такие коды не расшифровывались: из других явно записанных позиций выбрана
первая поддерживаемая; решение перечислено в `positionAdjustments`.
Имя игрока без исходного ID сопоставлено с единственным точным совпадением
по имени в существующем реестре; остальные идентификаторы устойчиво
выводятся из имени. Это не доказывает совпадение людей при иных написаниях.

Повторно создать снимки можно командой
`python3 scripts/build-user-rpl-2019-2021.py /папка/с/md`.
Импорт `scripts/import-rpl-2019-2021.mjs` добавляет эти три года,
отказывается заменять несовпадающие существующие данные и не меняет
составы 2010–2018.
