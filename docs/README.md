## Источники и исследования

Материалы `docs/research/` и импортируемые наборы описывают отдельные периоды и ограничения источников. Они не заменяют сверку текущей production-базы. Уникальных игроков нельзя складывать между наборами: один человек встречается в нескольких источниках.

## Исторические документы

Корневые `CHANGES.md`, `DEPLOY.md`, `PRODUCTION.md`, `PRODUCTION_CHECKLIST.md`, `TELEGRAM_AUDIT.md`, `TODO.md`, `PROJECT_ANALYSIS.md` и `30-0-GAME-DEV-DOC.md` заменены указателями на актуальные страницы; прежние версии доступны в истории Git. При расхождении используйте документы из таблицы выше и проверяйте реальный код.
