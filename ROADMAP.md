# План развития

Основан на [аудите 22 октября 2026](docs/audits/2026-10-22.md). Это план, а не обещание выполненных изменений.

| Приоритет | Работа | Критерий готовности |
|---|---|---|
| P1 | Восстановить SSH-деплой на Jino | Upload, restart и внешний verify проходят; установленный commit можно однозначно определить |
| P1 | Подтвердить доставку Telegram от события до устройства | Тест приглашения, заявки, результата и возврата; задача подтверждена в очереди, сообщение получено, повтор не дублирует его |
| P1 | Подготовить сезон 2026 | Источник, клубы, составы, позиции и RU/EN проверены; импорт с резервной копией; счётчик показывает фактическую базу |
| P2 | Закрыть advisory в dev-цепочке braces | Совместимые версии без отката Next.js; lint, build и интеграционные проверки проходят |
| P2 | Убрать устаревшую подсказку одного клуба | Описание прайма и допуска клубов совпадает с серверными правилами и ручными override |
| P2 | Минимизировать публичный leaderboard | Явный публичный DTO, без внутренних полей `GameRun`, пагинация и проверки доступа |
| P2 | Разделить health и обслуживание профилей | Короткий read-only health, скрытые внутренние ошибки, установленный commit определяется отдельно |
| P2 | Согласовать внутреннюю навигацию | Убрать три предупреждения; проверить возврат, восстановление и переходы в Mini App |
| P2 | Укрепить rate limit и выпуск релизов | Общие лимиты для процессов, доверенные proxy, защита main и обязательные CI-проверки |
| P2 | Разобрать неопознанные позиции источника 2021 | Три токена подтверждены источником или явно исключены; нет выдуманных позиций |
| P2 | Полный мобильный и доступностный прогон | Telegram iOS/Android, клавиатура, focus, screen reader, reduced motion; отчёт с реальными снимками |
| P3 | Обновить карточку публичного результата | Визуальный приоритет Mini App, больше контекста режима и состава, проверенные ссылки в историю |
| P3 | Продолжить нормализацию базы | Ручное подтверждение неоднозначных дублей и RU-имён, обратимые слияния, качество по сезонам |
| P3 | Решить лицензию и происхождение ассетов | Владелец выбирает лицензию; права на код, фото и эмблемы описаны без необоснованных обещаний |

До расширения функций приоритет — воспроизводимая доставка релизов и уведомлений, достоверные данные и понятные состояния игры. Новые режимы не заменяют эти проверки.
