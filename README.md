# 30-0 — драфт РПЛ

Неофициальная футбольная игра для браузера и Telegram Mini App. Соберите состав из 11 игроков разных сезонов РПЛ, сыграйте симулированный сезон из 30 матчей и попробуйте выиграть все 30.

**[Играть на 30-0.рф](https://30-0.рф/)** · **[Открыть в Telegram](https://t.me/RPL30_bot?startapp)** · **[Сообщество в Telegram](https://t.me/+iX9kd8CgQJxkYzFi)**

## Игровые режимы

| Режим | Правила |
| --- | --- |
| **Обычный драфт** | Колесо выбирает клуб и сезон из доступной базы. Выберите игрока и поставьте его на подходящую позицию. Повторите для всех 11 мест. |
| **Один клуб** | Сначала выберите клуб. Все прокрутки и игроки берутся из записанных в базе составов этого клуба; рейтинг соответствует выбранному сезону. Рейтинг Prime в этом режиме недоступен. |

Доступны 12 схем, три уровня сложности (3, 1 или 0 перебросов), совместимость позиций и необязательный случайный тренер с небольшим бонусом. После сборки состава игра моделирует 30 матчей против клубов из базы, формирует таблицу и показывает итоги, достижения и возможность поделиться результатом. Это **игровая симуляция**, а не реальные результаты матчей или прогноз.

Интерфейс поддерживает русский и английский языки. В профиле доступны история последних сезонов, статистика, трофеи и ссылка для приглашения. Вход через Telegram нужен для сохранения прогресса в аккаунте; играть можно и без входа. Мультиплеер скрыт из публичного интерфейса.

## Данные и ограничения

Публичный API показывает только сезоны с составами начиная с 2010 года; клубы режима «Один клуб» дополнительно проходят проверку достаточности игроков и позиций. Наличие клуба или года в исходных файлах **не означает**, что его состав целиком доступен в игре. Текущие числа клубов, сезонов и игроков можно проверить в [показателях приложения](https://30-0.рф/api/health) или в админке; они меняются при импорте.

Исходники составов и качество данных неоднородны. Для импортов 2019–2021 документировано происхождение предоставленных файлов и сохранены исходные рейтинги; старые генераторные файлы не следует выдавать за проверенный исторический архив. Рейтинг тренера — внутриигровая оценка. Подробности: [качество данных](docs/DATA_QUALITY.md), [импорт 2019–2021](docs/research/rpl-2019-2021/README.md), [FIFA 10](docs/research/fifa10-import-status.md), [тренеры 2010–2018](docs/research/rpl-managers-2010-2018.md).

## Разработка

Стек: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Zustand, Prisma. Локальная база — SQLite; production — MySQL/MariaDB на Jino. Node.js 22+ и npm:

```bash
git clone https://github.com/kr1sanov/30-0.git
cd 30-0
npm ci
cp .env.example .env
npm run schema:sqlite
npm run db:push
npm run db:seed
npm run dev
```

Откройте <http://localhost:3000>. Проверки: `npm run lint`, `npx tsc --noEmit`, `node --experimental-strip-types --test tests/*.test.ts`. Отдельный аудит старых файлов `npm run data:audit` сообщает о проблемах; его строгий вариант ожидаемо не проходит до исправления происхождения и полноты записей.

Админка по адресу `/admin` защищена отдельным логином и паролем; позволяет смотреть метрики, управлять доступом и составами, проверять CSV перед импортом и вручную добавлять игроков.

Проект независимый, создан фанатами и не связан с РПЛ или клубами. Отдельный файл лицензии для исходного кода в репозитории не опубликован.
